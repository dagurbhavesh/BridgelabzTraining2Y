DATA STRUCTURE - LINKED LIST: JAVA SOLUTIONS

Nine independent Java programs corresponding to the nine problems in the supplied LinkedList PDF:
1. Q1_StudentRecordSingly.java       - Student record management (singly linked list)
2. Q2_MovieManagementDoubly.java     - Movie management (doubly linked list)
3. Q3_TaskSchedulerCircular.java     - Task scheduler (circular linked list)
4. Q4_InventorySingly.java           - Inventory management and merge sort (singly linked list)
5. Q5_LibraryDoubly.java             - Library management (doubly linked list)
6. Q6_RoundRobinCircular.java        - Round-robin CPU scheduling (circular linked list)
7. Q7_SocialMediaFriends.java        - Friend connections (singly linked user list; friend IDs in ArrayList)
8. Q8_TextEditorUndoRedo.java        - Undo/redo with a maximum of 10 states (doubly linked list)
9. Q9_TicketReservationCircular.java - Ticket reservations (circular linked list)

HOW TO RUN
Open a terminal in this folder. Example:
  javac Q1_StudentRecordSingly.java
  java Q1_StudentRecordSingly

Each file has its own main method and sample data. Run one program at a time.
Insertion positions are 1-based. Round-robin processes are assumed to arrive at time 0.
